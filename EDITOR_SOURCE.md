# Fumadocs Editor — собственные исходники

Этот репозиторий содержит независимую копию [fuma-nama/fumadocs-editor](https://github.com/fuma-nama/fumadocs-editor) в каталоге `editor/`.

- **Источник:** `fuma-nama/fumadocs-editor`, ветка `dev`
- **Зафиксированная версия:** `46c7086bca2f77bd92fb51cc19871bf48c00e537` (1 октября 2026)
- **Лицензия:** MIT; оригинальный файл `editor/LICENSE` сохранён
- **Состав:** `editor/packages/core`, `editor/packages/ui`, `editor/packages/studio`, документация, playground, тесты и исходный `pnpm-lock.yaml`

## Разработка

```bash
cd editor
corepack enable
pnpm install
pnpm dev
# В другом терминале:
pnpm test
pnpm build
```

Для разработки требуется Node.js 24+. Внутри `editor/` находится **собственный** pnpm workspace; внешнее рабочее пространство Fumadocs в корне проекта не нужно менять. Все изменения, сделанные в `editor/packages/...`, коммитятся в этом репозитории напрямую — это обычные Git-файлы, не submodule.

**Важно:** импорт исходников не включает Editor в существующий сайт автоматически. Сайт должен явно зависеть от локальных пакетов редактора и иметь защищённую страницу редактирования. Актуальные Docker/Egg и интеграция Editor UI — отдельный шаг.

Для будущих обновлений upstream не удаляйте папку `editor/` и не накатывайте копию поверх изменённого кода без сравнения Git-изменений. GitHub workflow выполняет только первоначальное копирование и намеренно не перезаписывает редактор при повторном запуске.
